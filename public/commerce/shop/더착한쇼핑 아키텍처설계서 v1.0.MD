> 작성일: 2026-07 | 1차 철학 및 아키텍처 문서

## 1. 프로젝트 개요

### 1-1. 무엇인가
더착한쇼핑은 단순 e커머스가 아닙니다.
**생산자 + 상품 + 가게 + 소비자 + AI**를 하나의 생태계로 연결하는
"대한민국 생활경제 상생 플랫폼"입니다.

### 1-2. 기존 프로젝트와의 관계
- 기존 AI플랫마켓 코드: **절대 수정/삭제 금지**
- 위치: `public/commerce/shop/` 독립 모듈로 추가
- 향후: `shop.aiplatmarket.com` 서브도메인 운영 가능한 확장 구조
- AI Core: 모든 AI 요청은 ChatDoumi AI Core 경유 (직접 API 호출 금지)

### 1-3. 핵심 차별화
| 일반 오픈마켓 | 더착한쇼핑 |
|---|---|
| 상품 중심 | 스토리 중심 (생산자·가게·소비자 이야기) |
| 단순 검색/구매 | AI가 문맥·성향 분석 후 추천 |
| 거래 데이터만 축적 | 스토리·후기·행동 데이터 = 영구 플랫폼 자산 |
| 플랫폼 ↔ 셀러 분리 | 상생 구조 (AP Point로 참여자 전체 보상) |
| 중앙집중형 | 지역 밀착 (읍·면·동 센터 연계) |

## 6. AP Point 설계 원칙

### 6-1. 개요
- **공식 명칭**: AP Point (AIPlat Point)
- **약칭**: AP
- **표시 형식**: `AP 12,500P`, `예상 적립 +250 AP`, `보유 AP`

### 6-2. MVP 범위
- ✅ AP Point 잔액 표시 (UI)
- ✅ 상품별 예상 적립 AP 표시
- ✅ 회원가입 환영 AP 표시 (1,000AP)
- ❌ 실제 적립/차감 (Firebase 연동 후 구현)
- ❌ AP 사용하여 할인 (2차)

### 6-3. 절대 원칙 (법적 준수)
| 금지 사항 | 이유 |
|---|---|
| 현금 환전 불가 | 전자화폐/선불지급수단 규제 |
| 회원 간 송금 불가 | 자금이동 규제 |
| 투자·재테크 불가 | 유사수신 규제 |
| 외부 거래 불가 | 플랫폼 내부 한정 |

### 6-4. 확장 로드맵 (설계만, MVP 미구현)
```
Phase 1: AP Point (멤버십 리워드) ← 현재 MVP
Phase 2: AP Credit (플랫폼 내부 크레딧)
Phase 3: AP Pay (통합 결제)
Phase 4: 오프라인 QR/바코드 결제
Phase 5: AI플랫마켓 통합 경제 생태계
```

## 10. 핵심 아키텍처 철학

> GPT가 추천한 핵심 원칙:
> 
> "더착한쇼핑의 가장 큰 경쟁력은 상품이나 AI가 아니라 **데이터**입니다.
> 2~3년 후 AI플랫마켓의 핵심 경쟁력은 대한민국 생활경제 데이터 플랫폼이 될 것입니다."

따라서:
- 모든 상품·가게·스토리·후기·AI추천·라이브·검색·행동 데이터를 **구조화하여 누적**
- 지금 구축하는 더착한쇼핑은 "상품 파는 사이트"가 아니라 **AI 추천 + 지역경제를 연결하는 데이터 플랫폼의 시작점**
- 스토리 콘텐츠는 상품이 바뀌어도 영구히 남는 **플랫폼 자산**
