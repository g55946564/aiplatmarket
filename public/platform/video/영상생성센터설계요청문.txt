# AI플랫마켓 독립 프로젝트 「AI 영상생성센터」 MVP 전 설계 요청

AI플랫마켓의 독립 프로젝트로 「AI 영상생성센터」를 새롭게 설계한다.

## 1. 기본 정보

* 표시명: **AI 영상생성센터**
* URL/경로: **/video**
* 초기 구현 파일: **/video/index.html**
* 초기 단계에서는 여러 파일로 분리하지 말고 **HTML 1개 안에 HTML + CSS + JavaScript + 모든 주요 UI/UX를 통합 구현**한다.
* 기존 AI플랫마켓의 다른 독립 프로젝트들도 초기에는 단일 HTML MVP 방식으로 개발하고 있으므로 동일한 개발 철학을 따른다.
* 이후 실제 서비스 규모가 커질 때만 CSS/JS/API 등을 별도 파일로 분리한다.

## 2. 프로젝트의 핵심 목적

단순한 AI 영상 생성 도구가 아니다.

사용자가

**아이디어 → 콘텐츠 기획 → 대본 → 영상 제작 → 편집 → 썸네일 → 쇼츠 → 유튜브 게시 → 홍보 → 성장**

까지 이어서 이용할 수 있는 **독립형 영상·콘텐츠 제작 및 성장 플랫폼**을 목표로 한다.

즉,

> "AI로 영상을 만드는 곳"

을 넘어

> "아이디어를 콘텐츠로 만들고, 콘텐츠를 실제 활동과 성장으로 연결하는 곳"

으로 설계한다.

---

## 3. 기존 /media와의 역할 분리

기존 AI플랫마켓의 MEDIA(/media)는

* LIVE 홈쇼핑
* 뮤직방송
* 인터넷TV
* 미디어 콘텐츠 소비

등의 **미디어 소비 영역**이다.

반면 `/video`는

* 영상 제작
* 쇼츠 제작
* 콘텐츠 기획
* 영상 편집
* 썸네일
* 유튜브 제작
* 유튜브 성장
* 크리에이터 교육

등의 **콘텐츠 생산·제작·성장 영역**이다.

따라서 두 영역의 UI와 서비스 목적이 혼동되지 않도록 한다.

핵심 개념:

**/media = 본다**

**/video = 만든다**

## 4. 전체 IA

초기 주요 메뉴는 다음을 기준으로 설계한다.

### 홈

* AI 영상생성센터 소개
* 바로 제작 시작
* 빠른 제작 메뉴
* 최근 프로젝트
* 추천 제작 기능

### 제작

* AI 영상 만들기
* AI 쇼츠 만들기
* 유튜브 영상 제작
* 콘텐츠 기획
* 대본
* 스토리보드

### 편집

* 영상 편집
* 자막
* 음성
* 음악
* 장면 구성
* 화면비율

### 썸네일

* AI 썸네일
* 썸네일 문구
* 제목
* 썸네일 템플릿

### 성장

* 유튜브 성장지원
* 채널 분석
* 콘텐츠 분석
* 제목/썸네일 분석
* 성장 전략

### 교육

* 크리에이터 교육
* AI 영상 제작 교육
* 쇼츠 제작
* 유튜브 시작
* 콘텐츠 기획

### 내 콘텐츠

* 내 프로젝트
* 제작 중
* 완성 콘텐츠
* 대본
* 썸네일
* 성장 데이터

단, MVP에서는 위 기능들을 모두 실제 작동시키지 않는다.

**전체 서비스 구조를 UI/UX로 보여주되 핵심 제작 흐름을 우선 구현한다.**

---

## 5. 핵심 사용자 흐름

가장 중요한 UX는 다음 흐름이다.

사용자가 AI 영상생성센터에 들어오면 복잡한 메뉴부터 보여주는 것이 아니라,

### "무엇을 만들고 싶으신가요?"

를 중심으로 제작을 시작할 수 있게 한다.

예:

* 유튜브 영상
* 쇼츠
* 상품 홍보영상
* SNS 영상
* 자유 제작

사용자가 하나를 선택하면:

**주제 입력**
→ **콘텐츠 기획**
→ **대본**
→ **스토리보드**
→ **영상 제작**
→ **편집**
→ **썸네일**
→ **완성**
→ **게시/홍보**
→ **성장분석**

으로 이어지는 구조를 시각적으로 표현한다.

---

## 6. MVP에서 우선 구현할 핵심 영역

초기에는 다음 7개를 우선한다.

1. AI 영상생성센터 홈
2. AI 영상 만들기
3. AI 쇼츠 만들기
4. 콘텐츠 기획
5. 썸네일
6. 내 프로젝트
7. 유튜브 성장지원

실제 AI 영상 생성 API, 영상 편집 엔진, YouTube API 등은 MVP 후반 또는 다음 단계에서 연결한다.

---

## 7. AI 호출 구조

UI 코드 안에 특정 AI 모델 호출을 직접 넣지 않는다.

향후 AI Core와 연결할 수 있도록 독립 Hook/API 구조를 고려한다.

예상 구조:

generateScript()
generateStoryboard()
generateVideoPrompt()
generateThumbnail()
analyzeContent()
analyzeChannel()
generateGrowthPlan()

MVP에서는 실제 AI 호출 대신 Mock 데이터 또는 예시 결과를 사용해도 된다.

향후 AI Core와 연결할 때 UI를 다시 설계하지 않아도 되도록 인터페이스를 고려한다.

---

## 8. 다른 AI플랫마켓 서비스와의 연계

MVP에서는 실제 연동을 구현하지 않아도 되지만 향후 연결 구조를 고려한다.

### LifeMap

진로/관심분야
→ 콘텐츠 주제
→ 크리에이터 활동

### ItemZone

사업 아이템
→ 상품/서비스
→ 홍보영상 제작

### AI통합홍보센터

영상 제작
→ 홍보 콘텐츠
→ SNS/지역홍보/온라인 홍보

### 더착한쇼핑몰

상품
→ "상품 홍보영상 만들기"
→ AI 영상생성센터

### AI MetaZone

향후 가상공간의
영상관 / 크리에이터 스튜디오 / 방송공간 등으로 확장

단, MVP에서 과도한 연동 기능은 만들지 않는다.

---

## 9. 디자인 방향

AI플랫마켓의 공통 Header/GNB/Footer와 충돌하지 않는 독립 모듈형 디자인을 사용한다.

전체적으로:

* 전문적인 Creator Studio 느낌
* 너무 복잡한 전문 영상 편집 프로그램 느낌은 피함
* 일반 사용자도 쉽게 시작할 수 있는 UI
* 카드형 기능 선택
* 단계별 제작 흐름
* 큰 CTA
* 프로젝트 중심 화면
* PC/태블릿/모바일 반응형

을 기본으로 한다.

특히 첫 화면에서 기능을 나열하는 것보다 **"무엇을 만들 것인가?" → "바로 시작"**의 흐름을 강조한다.

## 11. 반드시 설계해야 할 화면

최소한 다음 화면 상태를 하나의 index.html 안에서 구현한다.

### A. 홈

AI 영상생성센터 메인

### B. 제작 선택

유튜브 / 쇼츠 / 상품홍보 / SNS / 자유제작

### C. 제작 Workspace

주제 입력 → 기획 → 대본 → 스토리보드 → 제작 준비

### D. 쇼츠 Workspace

세로형 9:16 콘텐츠 제작 UI

### E. 썸네일

썸네일 제작 UI

### F. 내 프로젝트

프로젝트 카드와 상태

### G. 성장지원

채널/콘텐츠 성장분석 UI Mock

각 화면은 실제 페이지 이동을 하지 않고 JS 기반 화면 전환으로 구현해도 된다.

---

## 12. 제작 화면에서 중요한 UX

영상 제작 화면은 향후 실제 AI 제작 기능이 연결될 것을 고려하여 다음 구조를 갖는다.

왼쪽:

* 제작 단계

중앙:

* 현재 작업 영역

오른쪽:

* 설정/미리보기/도움말

하단:

* 이전
* 저장
* 다음 단계
* 제작 시작

단, 모바일에서는 이 구조를 세로형으로 자동 변경한다.

---

## 13. 프로젝트 관리

사용자가 만든 콘텐츠를 프로젝트 단위로 관리할 수 있는 UI를 만든다.

예:

* 프로젝트명
* 콘텐츠 종류
* 제작 단계
* 마지막 수정
* 상태
* 계속 제작
* 복제
* 삭제

MVP에서는 LocalStorage 등을 이용한 간단한 저장 구조도 가능하다.

---

## 14. 중요한 개발 철학

처음부터 모든 기능을 완성하려 하지 않는다.

MVP 전 단계의 목적은:

**전체 서비스 구조를 눈으로 확인하고**
**사용자가 실제로 어떻게 이동하는지 검증하는 것**

이다.

따라서 실제 AI 생성보다:

* IA
* UI/UX
* 사용자 흐름
* 제작 Workspace
* 프로젝트 관리
* 반응형
* 향후 API 연결 구조

를 우선한다.

## 15. 최종 요청

먼저 실제 대규모 개발에 들어가기 전에 다음을 순서대로 검토하고 설계한다.

1. 전체 IA
2. 화면 구조
3. 사용자 Journey
4. 핵심 UX
5. MVP 범위
6. 향후 확장 구조
7. AI Core 연결 구조
8. 다른 AI플랫마켓 독립 프로젝트와의 연결 지점
9. 단일 HTML MVP 구조
10. 이후 파일 분리/서비스 확장 전략

그 다음 위 설계를 반영하여 **/video/index.html 단일 HTML MVP**를 제작한다.

처음부터 과도하게 많은 기능을 구현하지 말고,

**"사용자가 들어와서 아이디어를 입력하고 영상 제작을 시작하는 경험"**

이 가장 완성도 높게 느껴지도록 설계한다.
